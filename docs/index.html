The project

One workspace.
Purpose-built layers.

Aether is an evolving Linux desktop project developed around labwc and the Wayland ecosystem. Its goal is to bring the panel, quick controls, notifications, utilities, and settings together without obscuring the underlying system.

Rust is used for system-facing components and services, while TypeScript and React power selected application interfaces. Tauri connects the settings UI to native commands where appropriate.

Aether is a work in progress. This page describes the project's direction and architecture; individual capabilities may still be under development or require integration.

Inside Aether

Clear boundaries.
Shared purpose.

Aether separates desktop interaction, UI components, and system integration so each layer can evolve independently. The compositor remains responsible for window management.
