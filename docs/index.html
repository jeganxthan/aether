The idea

One desktop.
Thoughtfully put together.

Aether pairs labwc, a lightweight Wayland compositor, with a purpose-built desktop shell written in Rust. The shell brings the everyday pieces together: a panel, quick controls, notifications, settings, and clear feedback when system settings change.

The compositor remains labwc; Rust powers Aether’s shell, UI toolkit, and system services. Each part can evolve without pretending to be the other.
