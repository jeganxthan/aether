The idea

A complete desktop,
built one layer at a time.

Aether pairs labwc, a lightweight Wayland compositor, with a purpose-built desktop shell written in Rust. Aether brings the daily essentials into one cohesive workspace: a native panel, quick access to system controls, rich notifications, media controls, and a dedicated settings app.

The compositor remains labwc. Rust powers Aether’s shell, UI toolkit, and system services—clear boundaries, working together as one desktop.
